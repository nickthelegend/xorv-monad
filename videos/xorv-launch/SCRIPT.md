# SCRIPT — xorv-launch

**Voice:** am_michael (Kokoro, offline)
**Voice settings:** default
**Pronunciation:** acronyms are spelled letter-by-letter in the spoken text — `U S D C`, `H bar`, `M C P`. Kokoro collapses `USDC` into a single syllable otherwise (measured: 1.173s vs 1.707s for the same sentence).
**Voice direction:** Calm, assured, low-hype. The register of someone showing
you something that works, not selling you something. Never rushed, never
excited. Land the last word of each line and let the cut do the emphasis — the
motion is already doing the work, so the voice should not compete with it.
